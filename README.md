# Robots de collecte Opportafrik

Robots qui repèrent les offres (emplois, stages, concours, appels d'offres,
bourses) publiées par des sites africains et les signalent sur
[opportafrik.com](https://opportafrik.com) sous forme de **résumé + lien vers
l'annonce d'origine**.

Règles suivies :
- le fichier `robots.txt` et les conditions d'utilisation de chaque site sont respectés ;
- une pause de plusieurs secondes entre deux pages d'un même site ;
- aucun contournement : un site qui refuse les robots est désactivé ;
- jamais LinkedIn ; jamais de copie intégrale des annonces.

Un site souhaite ne plus être lu ? Écrivez à contact@opportafrik.com.

Les clés d'accès à la base sont rangées dans les secrets GitHub, jamais dans le code.
